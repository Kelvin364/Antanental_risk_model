## Design notes

- Green is used on the primary buttons and the active elements (the active step, the position
  bar, the priority pills).
- There is no logo mark.
- Step numbers and the account initials are plain text, with no circle backgrounds.
- The primary typeface is Host Grotesk, with a monospace face for the figures.
