## 1. Rules that never change

1. Never modify data/maternal_dataset_csv.csv. Its SHA 256 is ab95366ef22dde5d13df93f10723942f5faffda8fbf0007e8efe85e4f25c1126 and StudySpec.data_sha256 must keep matching it.
2. Never read, evaluate or open the held out partition (partitions/holdout_ids.csv) except through HoldoutEvaluator.evaluate_once with confirm_supervisor_reviewed=True, and only when the user writes the exact sentence "supervisor has reviewed the plan, run the holdout". Until then partitions/holdout_access.log must not exist.
3. Never regenerate partitions/holdout_ids.csv or partitions/folds.parquet. Their checksums are recorded in partitions/ and tested.
4. No class weighting, oversampling, undersampling or synthetic minority generation anywhere.
5. One cohort rule, one set of counts: 8,817, 8,609, 8,193, 8,161, 7,994, 6,203, 6,065, 3,908 with 206 events; development 3,126 with 165; held out 782 with 41; seed 20260930. A change to any of these is a bug, not a result.
6. Set C for linear models is set B plus visit one values only; difference and rate terms are tree only or sensitivity only.
7. Access is by sign in only. Accounts are administrator or researcher (decision D1); there is no public sign up, and only an administrator creates accounts, resets passwords and deactivates users. Passwords are stored only as scrypt hashes, never in git, code, tests or logs; a chosen first password comes from ANTENATAL_ADMIN_PASSWORD and must be changed at first sign in. Sessions are server side with HttpOnly cookies and CSRF tokens, and every account action is audited. No clinical risk category, priority label, triage band or "see sooner" wording anywhere in code, text, figures or designs.
8. Every number in README.md, docs/Technical-Report.md, docs/meeting_evidence.md and docs/STATUS_REPORT.md comes from a file in outputs/, a recorded test run or git. Never type a result.
9. Written text is plain English with no dashes or hyphens as punctuation, readable by someone who has not spoken to the author. Define a technical term the first time it appears.
10. The primary artefact webapp/model/lbw_model.joblib and its recorded checksum are frozen. Do not refit or replace it. The secondary set B artefact in webapp/model/secondary_set_b/ is also frozen.
11. Interface design: green primary buttons, no logo, no circles around numbers or letters, the synthetic banner on every screen.
12. Never push. The author pushes after running Section 5 below. Commit after every coherent change with an imperative message that says what and why, citing the proposal section, requirement (R1 to R16) or supervisor comment (C01 to C13) it serves.

## 2. Where things live

- src/antenatal: the research package (config, data, cohort, features, models, evaluation, artefact, reporting, cli).
- webapp/app: FastAPI application (api, services, schemas, db, core). webapp/static: the interface. webapp/model: frozen artefacts.
- notebooks/01_data_audit.ipynb and 02_model_notebook.ipynb: narrative over the package; no logic of their own.
- outputs/: every table, figure and manifest, regenerated by python -m antenatal run-analysis, run-extensions, summarise-results.
- partitions/: sealed held out ids, folds, checksums.
- tests/unit, tests/integration, tests/e2e.
- docs/: architecture, ethics note, deviations, TRIPOD+AI checklist, technical report, meeting evidence, status report, evidence/.
- scripts/: input_variation.py, record_test_results.py, benchmark_api.py, render_designs.py, build_report_pdf.py, package_attempt2.py.

Commands: make install, make test, make lint, make run-all, make serve, make notebook.
